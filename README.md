# 🚀 AI DevOps Copilot

## Overview
AI-powered DevOps assistant that analyzes infrastructure logs, detects root causes, and provides actionable fixes using OpenAI APIs.

## Features
- 🔍 Log analysis with root cause detection
- 💬 Chat-based DevOps assistant
- 📂 Log file upload support
- ⚠️ Severity classification (Critical/Warning/Info)
- 📥 Downloadable reports (TXT/JSON)

## Tech Stack
- Python
- Streamlit
- OpenAI API

## Use Cases
- Kubernetes pod failures
- Memory issues (OOMKilled)
- CI/CD pipeline debugging
- Cloud infrastructure monitoring

## How to Run
pip install -r requirements.txt  
streamlit run app.py
